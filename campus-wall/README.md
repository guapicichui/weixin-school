# 校园微墙

基于**微信原生小程序框架 + 微信云开发云函数**的校园社区第一版。使用 WXML、WXSS 和 JavaScript，无跨端框架依赖。

## 已实现

- 微信身份自动建立多用户账号，编辑昵称和个人介绍。
- 按话题浏览和发布文字帖子，查看详情、评论、点赞、收藏，查看自己的动态。
- 跑腿员申请、管理员审核，申请结果通过站内消息反馈。
- 发布跑腿需求、接单大厅、我的发单与接单、送达和完成确认。
- 评论和订单进展的站内消息，内容举报与管理员下架。
- 服务端身份校验、数据库事务防止重复接单、幂等提交、联系方式按订单参与者授权展示。

跑腿费采用**线下结算**。账号和跑腿员资料按微信身份区分；跑腿员审核为人工核验资料，不代表学校官方身份认证。

## 快速开始

1. 安装微信开发者工具，导入本目录（含 project.config.json 的 campus-wall 目录）。
2. 在工具项目设置中换成你的小程序 AppID。
3. 在 miniprogram/config.js 填写微信云开发环境 ID。
4. 按 [部署指南](docs/DEPLOYMENT.md) 创建数据库集合、配置规则、部署 campus 云函数。
5. 在真机上使用至少三个账号完成发帖互动与发单接单验收。

小程序全部业务通过 wx.cloud.callFunction 调用 campus 云函数；action 指定业务方法，data 为参数。后端以 Node.js JavaScript 编写，按模块组织，不需要自行部署 HTTP 服务器。

## 项目内容

| 路径 | 内容 |
|---|---|
| miniprogram/ | 原生小程序页面、公共样式、SDK 调用 |
| cloudfunctions/campus/ | 云函数入口、业务服务、权限和数据库适配 |
| tests/ | 多用户、并发接单、权限、幂等和状态流转测试 |
| scripts/check-project.js | 静态工程检查 |
| docs/ | 部署、数据模型、接口和验收说明 |

## 本地验证

需要 Node.js 18 或更新版本；核心测试无第三方依赖：

~~~sh
npm test
npm run check
~~~

云函数部署时，单独在 cloudfunctions/campus 安装依赖，或使用微信开发者工具的“上传并部署：云端安装依赖”。
