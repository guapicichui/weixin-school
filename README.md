# weixin-school · 校园微墙

微信原生小程序 + 微信云开发云函数。

项目源码位于 [campus-wall/](campus-wall/)，请使用微信开发者工具导入该目录。

已实现多用户资料、话题帖子、评论点赞收藏、跑腿员申请与审核、发单接单和完成确认、站内通知与内容举报。

- [项目说明](campus-wall/README.md)
- [部署指南](campus-wall/docs/DEPLOYMENT.md)
- [接口约定](campus-wall/docs/API.md)
- [验证范围](campus-wall/docs/VALIDATION.md)

需要配置自己的 AppID 和云环境 ID。跑腿费采用线下结算。
